# Palintropy

Palintropy is the operating layer of Persistence Dynamics: a way for people and AI agents to work according to the theory. It is built on the theory, and it is not part of it. [Encounter](../encounter/) applies Palintropy to the cancer domain.

Its record follows the **Palintropy Work Protocol (PWP)**. In the PWP, everything is a unit, and a unit is a Change Unit. A unit has needs on four sides (Gathering, Building, In use, Kept), and where it stands is read from which needs are met.
