# The Persistor

**A persistor is the unit of change: one cycle that creates the structure for the next cycle to build on.** Everything that persists is a persistor. Every persistor contains persistors and sits inside one.

The same concept appears in different shapes under three names:
- **Persistor**: the public name, used on this site.
- **Change Unit**: the name used in the canon reference below.
- **Quadragen**: the name used in earlier pages and code.

- [canon.md](canon.md): the full canon reference, covering the definition, the five axioms, the regime types, the formal core, recursion rules R1 to R13, the five dimensions and the open seams. It was imported from the working canon on 2026-11-24 and is being edited for publication.

Before publication, the canon's terms will be aligned with [theory/](../theory/), where the v2 terminology is canon.
