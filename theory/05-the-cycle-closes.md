# The cycle closes

A round is complete when what leaves Conservation becomes the material for the next Potentiality. This is closure. A system that returns to where it started without producing anything reusable has run for nothing. Closure means the cycle gives back what it received and also produces what the next round will run on.

Closure also sets the scale between levels, because every closed cycle feeds the one above it. Let *d* be the fraction a cycle hands to the level above: its first-order reach. That level hands on the same fraction in turn, so *d*² of the original reaches two levels up: second-order reach. φ, the golden ratio, is not chosen. It is the only positive ratio at which the recursion closes, and it enters the theory here and nowhere else. Every φ that appears later descends from this one equation.

The geometry does not change between a cell, a clinical trial, an organisation and a career. The substrate changes; the four regimes, the order and the closure condition stay the same.
