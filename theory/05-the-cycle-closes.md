# The cycle closes

A round is complete when what leaves Conservation becomes the material for the next Potentiality. This is closure: the cycle gives back what it received, and also produces what the next round will run on. Without closure there is no persistence, only a single event.

Closure also sets the scale between levels. If the cycle one level up has the same shape as the cycle below it, the ratio *d* between the two levels must satisfy

This is the only place where φ enters the theory. Every φ that appears later descends from this equation. It rests on one assumption, that the recursion is self-similar, and that assumption is stated, not yet derived.

The geometry does not change between a cell, an organism and an organisation. The material changes; the four regimes, the order and the closure condition stay the same. That is what makes the theory portable, and it is also where the theory would fail most clearly if it is wrong.
